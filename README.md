# 두뇌 놀이터 (Brain Solution)

어르신 인지능력 향상·치매 예방을 위한 두뇌 놀이 모음입니다. 모바일 웹, 가로 화면용으로 만들었습니다.

- 바로 해 보기: https://donkeyju.github.io/Brain/ (GitHub Pages)
- 빌드 도구 없이 바로 돌아가는 정적 웹 페이지예요. `index.html`을 웹 서버로 열면 됩니다.
  예) `python3 -m http.server 8000` 후 `http://localhost:8000` 접속
- 문제는 매번 난수로 새로 만들어지고, 2판 연속 맞히면 한 단계 오르고 2판 연속 틀리면 한 단계 내려가요(1~5단계).
- 화면에는 감점을 보여주지 않고, 판마다 원자료(정답·선택·시간·보조 사용)를 모두 기록해요. 보호자용 기록 화면에서 CSV·JSON으로 내려받을 수 있어요.

## 카테고리와 놀이 (v0.12.0, 19개)

| 카테고리 | 놀이 |
|---|---|
| 기억력 | 수건돌리기, 과일 떨어지기, 장보기 목록 기억 |
| 집중력 | 가나다 떨어지기, 숫자 차례로 누르기, 다른 그림 찾기 |
| 계산력 | 시장 거스름돈, 기차 시간 계산, 벌집 숫자 만들기 |
| 논리력 | 규칙 찾기, 조건 맞는 이웃 찾기, 과일 칸 채우기 |
| 언어력 | 속담 놀이, 단어 맞추기, 숨은 낱말 찾기, 흉내말 맞추기 |
| 공간지각 | 길찾기, 같은 모양 찾기, 빈칸에 그림 맞추기 |

## 파일 구조

```
index.html          화면 틀 (처음·놀이 고르기·규칙·준비·놀이·결과·기록)
css/style.css       모든 화면 모양
js/core.js          공통 도구: 카테고리, 난수, 한글 도구, 점수, 저장(Store), 소리
js/app.js           공통 진행: 화면 이동, 판 진행, 채점, 난이도 조절, 기록 화면
js/games/*.js       놀이 하나에 파일 하나 (registerGame으로 등록)
js/games/*-data.js  목록형 자료 (속담, 단어, 흉내말)
docs/               기록·점수 설계 문서
```

## 새 놀이 추가하기

1. `js/games/새놀이.js`를 만들고 `registerGame({ id, category, name, ... })`으로 등록해요. 비슷한 놀이 파일을 복사해서 시작하면 쉬워요.
2. `index.html`의 `js/app.js` 줄 위에 `<script src="js/games/새놀이.js"></script>`를 넣어요.
3. 놀이 모양은 `css/style.css`의 `/* ---------- 결과 화면 ---------- */` 위에 넣어요.

## 기록 저장 위치

Claude 저장소 → (안 되면) 이 기기 브라우저(localStorage) → 임시 저장 순서로 씁니다.
GitHub Pages에서 열면 Claude 저장소가 없으므로 **그 기기의 브라우저에만** 저장돼요(브라우저 기록을 지우면 사라짐). 기록 화면의 "CSV 파일 받기"로 내려받아 보관하세요. 회사 서버로 옮길 때는 `js/core.js`의 `Store.write`와 `Store.loadHistory` 두 함수만 바꾸면 됩니다.
