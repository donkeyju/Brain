# 두뇌 놀이터 — 기록·점수 설계 (v0.13.0, 모든 놀이 공통)

원칙: 화면에는 감점을 보여주지 않고, 기록에는 판별 원자료를 모두 남긴다. 점수 공식은 나중에 바뀔 수 있으므로 원자료(정답·선택·시간·보조 사용)를 함께 저장한다.

## 판별 기록 (trial) — 모든 놀이 공통 칸
- 식별: trialId, sessionId, gameId(towel/fruit/shop/letters/numorder/spot/change/train/honey/pattern/neighbor/latin/proverb/word/hidden/mimic/route/shape/puzzle), category(memory/focus/calc/logic/language/space), playerLabel, roundNo, startedAt, answeredAt, appVersion
- 조건: level, levelAfter, questionType, seed(같은 판 재현용)
- 결과: accuracyScore, correct, trialScore, levelWeight, weightedScore
- 시간: rtFirstMs(질문 후 첫 터치), rtTotalMs(마지막 터치/다 했어요)
- 보조 사용: replayUsed(답하기 전 다시 보기), reviewCount(답한 뒤 천천히 다시 보기), pauseCount, pauseMs
- detail: 놀이별 칸 (CSV에서는 d_ 로 시작하는 열)
  - 수건돌리기: nPeople, direction, lapSec, fakeCount, towelCount, seatNames, choiceOrder, answerNames, chosenNames
  - 과일 떨어지기: nFruits, nBaskets, dropMode, path, swapCount, fruits, homeBaskets, finalSlots, askedFruits, askedSlot, answer, chosen
  - 장보기 목록 기억: shopType(pick/missing), listN, list, showMs / 고르기: shelf, picked, hits, falses(목록에 없던 것을 고른 수), misses(빠뜨린 물건), falseLooksLike(잘못 고른 것 중 목록 물건과 비슷해 보이는 것) / 빠진 물건: basket, options, missing, chosen
  - 가나다 떨어지기: letterType(color/read/similar), buttons, count, fallMs, gapMs, colorHint, hits, misses, falsePresses(화면에 없는 글자를 누른 수), falseDetail, rtMs(글자마다 잡기까지 ms), meanRtMs, meanFallPct, sequence, caught(O/X 차례)
  - 숫자 차례로 누르기: orderType(up/down/mix), n, dotSize, errors, hints, wrongTaps(찾던 것→누른 것), stepMs, meanStepMs, maxStepMs, layout
  - 다른 그림 찾기: diffType(basic/color/move), cols, rows, nDiffs, found, wrongTaps, gaveUp, diffs(종류:원래→바뀐 것@왼쪽/오른쪽), foundKinds, missedKinds, tapLog
  - 시장 거스름돈: calcType(total/change/pay), items, correct, paid, options, chosen, diff(−1000 받아올림 실수, +1000 받아내림 실수) / 딱 맞게 내기: paidPieces, paidSum, diff, pieces, fewestPieces, edits
  - 기차 시간 계산: timeType(clock/arrive/duration/compare), start, duration, end, clockTime, blueArrive(자정부터 분), correct, options, chosen, carryNeeded, crossNoon, diffMin(±60이면 시 계산 실수)
  - 벌집 숫자 만들기: k(고를 개수), cells, target, picked, sum, diff(합 − 목표), solutions(맞는 방법 수), carry(받아올림 문제), edits
  - 규칙 찾기: patternType(ab/abc/aab/abb/aabb/size/grow/shrink), length, blankIndex, sequence, options, chosen, rule
  - 조건 맞는 이웃 찾기: template(one/and/not/andnot), condA, condB, condition, nPeople, people, answerName, chosenName, nearMissCount, chosenHasA, chosenHasB
  - 과일 칸 채우기: gridType(row/full/cross/chain), n, steps, useCol(세로줄도 봐야 하는지), fruits, results(칸:고른 과일→정답), okCount, blanks
  - 속담 놀이: proverbId, proverb, difficulty, wordCount, seenBefore, firstSeen, reviewItem, edits, blankText, blankPos, distractors, optionIds, chosen
  - 단어 맞추기: word, wordCategory, length, blankIndex, blankCount, blankPos, correct, options, chosen, hint(cho/cat/none), seenBefore, firstSeen
  - 숨은 낱말 찾기: category, n, k, showList(낱말을 보여줬는지), words(낱말@시작칸 방향), found, missed, wrongTries(이어지지 않는 글자를 누른 수), gaveUp, taps, grid
  - 흉내말 맞추기: mimicType(fill/who), domain(animal/sound/move), sentence, answerWord, options, chosen, nearOptions(같은 영역 오답 수)
  - 길찾기: gridCols, gridRows, start, goal, target, blockedCount, shortest, steps, routeLength, answerPath, userPath, moves, undoCount, chosen, places
  - 같은 모양 찾기: shapeType(same/turn/mirror), gridN, blocks, target, angle, options(종류@각도), chosenKind(correct/moved/mirror), chosenAngle
  - 빈칸에 그림 맞추기: puzzleType(other/look/turn), cols, rows, pieces, missing, missingObj, picture, options, chosenKind(correct/other/look/turn), chosen
- 0.3 이하의 예전 수건돌리기 기록은 불러올 때 gameId=towel, detail로 자동 변환한다. 기억력 카테고리 id(memory)는 바뀌지 않았으므로 예전 기록도 그대로 기억력으로 모인다.

## 한 번(회차)에 하는 판 수
놀이 등록 시 rounds 값으로 정한다.
- 5판: 수건돌리기, 과일 떨어지기, 장보기 목록 기억, 속담 놀이, 길찾기, 가나다 떨어지기, 숫자 차례로 누르기, 다른 그림 찾기, 숨은 낱말 찾기(한 판이 긴 놀이)
- 8판: 시장 거스름돈, 기차 시간 계산, 벌집 숫자 만들기
- 10판: 단어 맞추기, 흉내말 맞추기, 규칙 찾기, 조건 맞는 이웃 찾기, 과일 칸 채우기, 같은 모양 찾기, 빈칸에 그림 맞추기
회차 점수는 판 평균이라 판 수가 달라도 비교할 수 있다.

## 점수 공식 (공통)
- accuracyScore
  - 한 개 고르기: 맞음 100 / 틀림 0 (수건 "먼저 받은 사람"에서 두 번째 사람을 고르면 50)
  - 두 개 순서 고르기: 순서까지 100 / 순서만 바뀜 50 / 하나만 맞음 25 / 0
  - 속담 빈칸·순서: 제자리에 맞은 글자(조각) 비율 × 100
  - 길찾기 찾아가기: 도착하면 (가장 짧은 칸 수 ÷ 움직인 칸 수) × 100, 도착 못 하면 0
  - 길찾기 보고 따라가기: 할머니와 같은 칸에 있었던 걸음 비율 × 100
  - 거스름돈 딱 맞게 내기: 낸 돈 합계가 정확하면 100, 아니면 0
  - 가나다 떨어지기: 잡은 글자 비율 × 100
  - 숫자 차례로 누르기: n ÷ (n + 잘못 누른 수) × 100
  - 다른 그림 찾기: 찾은 곳 비율 × 100
  - 장보기 목록 고르기: (맞게 고른 수 − 잘못 고른 수) ÷ 목록 수 × 100 (0 아래는 0)
  - 벌집 숫자 만들기: 고른 숫자의 합이 목표와 같으면 100 (맞는 방법이 여러 개면 어느 것이든)
  - 과일 칸 채우기: 맞게 채운 칸 비율 × 100 (틀려도 정답을 채워 두고 다음 칸으로 넘어간다)
  - 숨은 낱말 찾기: 찾은 낱말 비율 × 100
- correct(맞음, 난이도 조절에 씀): 기본은 accuracyScore = 100. 아래 놀이는 isRight로 따로 정한다.
  - 가나다 떨어지기: 놓친 글자 1개 이하 + 잘못 누름 2번 이하
  - 숫자 차례로 누르기: 잘못 누름 1번 이하 + 알려주기 0번
  - 다른 그림 찾기, 숨은 낱말 찾기: 모두 찾음
- trialScore = accuracyScore × (답하기 전 다시 보기 썼으면 0.8, 아니면 1)
- levelWeight = 1 + 0.1 × (단계 − 1) → weightedScore = trialScore × levelWeight
- 반응시간은 점수에 섞지 않고 별도 지표로 본다. 집중력 놀이는 시간 지표가 핵심이다.
- 오답 종류(chosenKind·diff·falsePresses·wrongTaps·falseLooksLike)는 점수에 섞지 않고 어떤 실수가 많은지 보는 보조 지표로 쓴다.

## 놀이별 출제 규칙

### 장보기 목록 기억 (조합형)
- 물건 18가지(과일 8 + 우유·빵·달걀·두부·생선·당근·배추·양파·감자·옥수수)에서 목록을 고른다. 바로 앞 판 목록과는 겹치지 않는다.
- 3단계부터 선반에 목록 물건과 같은 색 무리의 물건을 먼저 놓아 헷갈리게 한다.
- 목록은 하나씩 나타나고 이름을 읽어준 뒤 사라진다.

### 가나다 떨어지기 (조합형)
- 글자 14자(가~하)에서 버튼 3~6개. 1~2단계는 가나다 차례 글자, 4~5단계는 비슷한 글자 짝(가·카, 다·타, 바·파, 자·차) 1~2쌍. 같은 글자가 세 번 이어지지 않는다.
- 같은 글자가 여럿 떨어지면 땅에 가장 가까운 것부터 잡힌다. 화면을 벗어나면 시간이 멈춘다.

### 숫자 차례로 누르기 (조합형)
- 동그라미끼리 겹치지 않게, 차례끼리 너무 가깝지 않게 배치한다. 9~12초 못 찾으면 다음 것이 깜빡인다(알려준 판은 맞음이 아님).

### 다른 그림 찾기 (조합형)
- 동네 그림(SceneArt)을 쓴다. 다른 곳은 서로 떨어진 칸에서 고르고 왼쪽·오른쪽에 섞는다. 바뀐 물건·색은 그림에 없는 것만.

### 시장 거스름돈 / 기차 시간 계산 (조합형)
- 거스름돈: 값은 단계별 단위의 배수. 오답은 받아올림(−1,000)·받아내림(+1,000) 실수 값을 먼저.
- 기차: 시각은 자정부터 분으로 셈한다. 오답은 시를 안 올린 값(−60)·안 빌린 값(+60)·바늘을 바꿔 읽은 시각을 먼저.

### 벌집 숫자 만들기 (조합형)
- 정답 숫자를 먼저 정하고 합을 목표로 삼는다. 나머지 칸에는 정답 숫자 하나만 바꾼 "거의 맞는" 숫자를 같은 방향으로 섞는다(둘 다 바꾸면 다시 맞는 답이 생기지 않게).
- 맞는 방법은 숫자 2개 문제는 2가지까지, 3개 문제는 3가지까지 허용한다. 3·5단계는 일의 자리 받아올림이 꼭 생긴다.

### 규칙 찾기 / 조건 맞는 이웃 찾기 (조합형)
- 규칙 찾기: 과일 그림만, 한 가지만 바뀜. 비슷한 과일은 한 문제에 같이 쓰지 않는다.
- 조건 맞는 이웃 찾기: 정답 한 분을 먼저 고르고 나머지는 조건에 맞지 않는 분으로 채운다.

### 과일 칸 채우기 (조합형)
- 줄마다 과일이 한 번씩인 판(라틴 방진)을 난수로 섞어 만든다. 비슷해 보이는 과일은 한 판에 같이 쓰지 않는다.
- 매 칸은 "지금 보이는 가로·세로줄만으로 답이 하나"인지 자동 확인한다. 가로·세로 문제는 한쪽 줄만으로는 답이 안 나오게 만든다.

### 속담 놀이 (문항 은행형)
- 은행: js/games/proverb-data.js, 109문항. 문항 번호는 바꾸지 않는다. 최근 40판에 나온 속담은 우선 뺀다. 지표는 처음 본 문항과 다시 본 문항을 나눠 계산한다.

### 단어 맞추기 / 숨은 낱말 찾기 (조합형, 같은 단어 목록)
- 단어 목록: js/games/word-data.js, 12개 범주 322단어.
- 단어 맞추기: 정답이 둘이 되는 빈칸·오답 글자는 자동으로 뺀다.
- 숨은 낱말 찾기: 한 범주의 낱말을 가로·세로로 겹치지 않게 숨기고, 빈칸 글자로 목록 낱말이 우연히 생기면 다시 채운다. 한 낱말이 다른 낱말 안에 든 조합은 쓰지 않는다.

### 흉내말 맞추기 (목록형)
- 목록: js/games/mimic-data.js, 61문장(동물 소리 17, 사물·자연 소리 19, 모양·움직임 25). 같은 회차 안에서는 같은 문장을 내지 않는다.
- 같은 문장에 둘 다 맞을 수 있는 말은 같은 묶음(g)이라 오답으로 함께 나오지 않는다. 1~2단계 오답은 다른 영역에서, 3단계부터 같은 영역에서 먼저 고른다.

### 길찾기 / 같은 모양 찾기 / 빈칸에 그림 맞추기 (조합형)
- 길찾기: 공사 중인 길은 항상 돌아갈 수 있게 확인한다.
- 같은 모양 찾기: 오답은 블록 하나만 옮긴 모양. 돌리거나 옮겨서 같아지는 오답은 자동으로 뺀다.
- 빈칸에 그림 맞추기: 오답은 다른 자리 조각 / 가장자리 안 맞는 조각 / 돌아간 조각. 보기 조각이 서로 다른지 자동 확인.

## 회차 요약 (session)
sessionId, gameId, category, nTrials, correctCount, sessionScore, weightedScore, meanRtMs, startLevel→endLevel, maxLevel, resetFrom(초기화 뒤 첫 회차면 돌리기 전 단계, 아니면 빈칸), replayTotal, reviewTotal, pauseTotal, completed

## 난이도
놀이별로 따로 저장(profile.levels). 2판 연속 맞음 → 한 단계 위, 2판 연속 틀림 → 한 단계 아래 (1~5단계).
- 수건돌리기: 이웃 수, 술래 속도, 놓는 척 횟수, 문제 유형.
- 과일 떨어지기: 과일 2~5개, 바구니 3~6개, 하나씩→동시에, 떨어지는 길, 자리 바꾸기 0~3번.
- 장보기 목록 기억: 3개·선반 6칸·2.2초씩 → 4개·8칸 → 비슷한 물건·빠진 물건 찾기 → 5개·10칸 → 6개·12칸·1.6초씩.
- 가나다 떨어지기: 버튼 3개·6.5초·색 같음 → 4개 → 색 힌트 없음 → 비슷한 글자 1쌍 → 6개·4.2초·2쌍.
- 숫자 차례로 누르기: 8개 → 10개 → 12개 → 거꾸로 → 14개·숫자·글자 번갈아.
- 다른 그림 찾기: 1군데 → 2군데·색 → 4×3·3군데 → 자리 옮김 → 5×3·4군데.
- 시장 거스름돈: 천 원 → 500원 → 딱 맞게 내기 → 100원·보기 4개 → 물건 3개·큰돈.
- 기차 시간 계산: 시계·도착(30분) → 걸린 시간 → 먼저 도착(10분) → 5분·보기 4개 → 낮 12시 넘나들기.
- 벌집 숫자 만들기: 십 단위 2개 → 5 단위 → 받아올림 → 3개·9칸 → 3개·10칸·받아올림.
- 규칙 찾기: AB → ABC → AAB·ABB·크기 → AABB·개수 늘기 → 개수 줄기.
- 조건 맞는 이웃 찾기: 조건 하나 → 옷 무늬 → 두 조건 → 6~7명 → 부정 조건.
- 과일 칸 채우기: 3칸 한 줄 → 3×3 가로줄 → 가로·세로 → 2칸 차례로 → 4×4 3칸 차례로.
- 속담 놀이: 빈칸 2~6글자, 방해 글자 1~4개, 뜻 보기 2~4개, 순서 조각 3~7개.
- 단어 맞추기: 범주+첫소리 힌트 → 범주 힌트 → 보기 4개 → 비슷한 글자 → 힌트 없음.
- 숨은 낱말 찾기: 3×3 가로 1개 → 4×4 가로 2개 → 세로 추가 → 5×5 3개·범주만 → 5×5 4개.
- 흉내말 맞추기: 동물 소리 → 사물·자연 소리 → 모양·움직임·같은 영역 오답 → 보기 4개 → 누구의 소리.
- 길찾기: 4×3 지도 → 공사 1곳 → 따라가기 → 6×4 → 공사 4곳·따라가기 6~8칸.
- 같은 모양 찾기: 3×3 그대로 → 블록 4~5개 → 돌린 보기 → 4×4 → 거울 오답.
- 빈칸에 그림 맞추기: 6조각 → 가장자리 안 맞는 조각 → 12조각 → 돌아간 조각 → 15조각.

## 1단계부터 다시 (놀이별 난이도 초기화, v0.13.0)
- 놀이 설명 화면 아래에 "지금 ○단계"와 "1단계부터 다시" 버튼이 있다. 이미 1단계면 버튼을 숨긴다. 누르면 "1단계부터 다시 할까요? 그동안의 기록은 그대로 남아요"를 한 번 더 묻는다.
- 그 놀이의 단계만 1로 돌린다. 판·회차 기록은 지우지 않는다. 처음 화면에는 전체 초기화를 두지 않는다(실수로 모든 놀이가 초기화되는 것을 막기 위해).
- 기록: profile.levelResets에 {gameId, category, from(돌리기 전 단계), to: 1, at(시각), appVersion}을 쌓는다(최근 300건). 초기화 뒤 첫 회차의 session.resetFrom에 돌리기 전 단계를 적는다(앱을 껐다 켜도 마지막 초기화 시각과 마지막 회차 시각을 비교해 판단).
- 지표를 볼 때: resetFrom이 있는 회차부터는 단계가 1로 내려가 levelWeight·weightedScore가 갑자기 낮아지므로, 추세를 볼 때 초기화 지점을 구분해 본다. 보호자용 기록 표의 "단계" 칸에도 "○단계에서 1단계로 다시"가 표시된다.
